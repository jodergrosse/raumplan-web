# RaumPlan – Webseite

Quelltext der Produktwebseite [raumplan-app.de](https://raumplan-app.de) für RaumPlan.

RaumPlan ist eine kostenlose App für iPhone, iPad, Mac und Apple Vision Pro. Sie macht aus einem LiDAR-Scan mit dem iPhone Pro einen Grundriss, den man korrigieren und bearbeiten kann, zeigt ihn in 3D und exportiert ihn als SVG, DXF und weitere offene Formate. Die App hat kein Konto, keine Werbung und erhebt keine Daten. RaumPlan ist ein privates Hobbyprojekt.

Die Seite besteht aus HTML und CSS mit einem kleinen Skript für die Bildergalerie, ohne Cookies, ohne externe Schriften und ohne Tracking. Sie liegt auf GitHub Pages.

- `index.html`, `support.html`, `datenschutz.html`, `impressum.html`: deutsche Fassung
- `en/`: englische Fassung
- `kurzinfo.html`, `RaumPlan-Kurzinfo.pdf`: Kurzinfo zum Drucken
- `assets/`: Stylesheet, App-Symbol und Screenshots

Fragen, Rückmeldungen und Fehlermeldungen zur App gerne über die [Support-Seite](https://raumplan-app.de/support.html).
